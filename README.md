# 漫序 Studio

漫序 Studio 是面向独立创作者的 macOS 漫剧工作台。可以在同一个项目里整理角色卡、用本地模板编排提示词、写分镜，再用参考片采样画面。

## 下载和安装

当前安装包适用于搭载 Apple 芯片的 Mac。下载 `Manxu-Studio-macOS-arm64.dmg`，打开后将「漫序 Studio 公开版」拖入「应用程序」。校验文件和该版本的签名、公证状态见发布页。 [下载最新公开版](https://github.com/xiaohantiko/manxu-studio-showcase/releases/latest)

## 开始一个项目

1. 打开「项目空间」，点「新建项目」。也可以先打开自带的虚构示例《灯塔来信》，看看角色、提示词和分镜如何配合。
2. 在「角色卡片」里填写角色外貌、服装和需要保持一致的特征，可上传一张参考图。保存后，这张卡片能在「提示词工坊」里关联到当前场景。
3. 在「提示词工坊」里选择视频提示词、图像提示词、角色设定或镜头优化。填入场景和约束，用本地模板编排提示词，再编辑、保存版本、复制或导出文本。可将导出的文本带入自己的生成工具使用。
4. 在「分镜脚本」里安排镜头，记录场景和动作，完成后点「导出分镜」。在「参考片拆解」中导入视频或图片，可以在本机采样画面，再把拆解结果导出为文本。建议使用 H.264 MP4，单个视频最多 200 MB，图片最多 4 MB。

项目保存在当前设备的公开版工作空间。「项目空间 → 导出备份」可保存当前项目、角色、分镜和当前提示词为 JSON。「导入项目」可读取最多 25 MB 的备份文件，并创建项目副本。提示词历史版本可在工坊里单独导出需要保留的文本。

## 从源码运行

需要 Node.js 22.12 或更新版本以及 npm。在仓库目录运行以下命令，打开终端里显示的本地地址可预览网页界面。

```sh
npm ci
npm run dev
```

在 macOS 上运行桌面版或执行逻辑检查时，分别使用以下命令。

```sh
npm run build
npm start
```

```sh
npm run check
```

历史版本的功能变化见 [更新日志](CHANGELOG.md)。
