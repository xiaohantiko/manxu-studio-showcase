# 漫序 Studio 公开版

在 Mac 上把一个漫剧想法写成可以拍摄的分镜脚本。你可以用本地模板编写和修改提示词，保存角色的外貌与固定特征，逐镜安排动作和声音，并从参考片中抽取画面，研究构图与连续性。自带虚构的《灯塔来信》和六节新手课程，创作数据保存在本机。

## 安装与更新

1. 下载 DMG 并打开，将「漫序 Studio 公开版.app」拖入「应用程序」文件夹，随后推出磁盘映像。
2. 在「应用程序」中打开公开版。它使用独立的本机工作区。当前发行包面向 Apple Silicon，采用本地签名，尚未完成 Apple 公证。
3. 更新时，保存正在编辑的角色卡、提示词并退出应用。将新版拖入上次安装的位置，访达询问时选「替换」。这样在启动器中只保留一份公开版。每个版本的下载页附有校验文件，下载后可用 `shasum -a 256 Manxu-Studio-macOS-arm64.dmg` 核对。

## 用 15 秒练习完成第一幕

1. **建项目。** 在「项目空间」点「新建项目」，输入“末班灯”和一句话故事“一名检票员关灯时，看见最后一盏灯又亮了”。选择 9:16 和 15 秒，再创建项目。
2. **固定角色。** 在「角色卡片」点「新建角色卡」，写入检票员的外貌，把“深蓝短外套、左胸圆形工牌”设为固定特征，再点「保存角色卡」。
3. **写两版提示词。** 在「提示词工坊」选择刚创建的角色，输入“关灯，停手，回头”。点「生成提示词」，读过结果后点「保存版本」。在结果区修改一句动作描述，再输入修改要求，点「重新优化提示词」并另存一版。「版本记录」可以找回保存过的稿件。
4. **排镜头。** 在「分镜脚本」点「添加镜头」，用 4 秒全景交代候车室、6 秒中景表现回头、5 秒特写落到工牌。逐镜填写动作、声音和运镜，再导出脚本。
5. **对照参考片。** 在「参考片拆解」拖入本地视频，推荐使用不超过 200 MB 的 H.264 MP4。六张带时间的画面在本机提取，可对照景别、人物位置和构图。音轨可以在原片播放器里试听。「查看示例拆解」会打开内置的虚构复盘，便于学习怎样区分画面观察和制作推测。

「新手学院」每节课都有「去试一试」入口。做完练习可点「标记本节完成」，下次打开 Mac 版时查看进度。

## 备份和恢复

在「项目空间」选中项目后点「加密导出备份」，设置至少 12 个字符的独立文件密码。将生成的 `.manxu` 文件存到备份位置，并单独保存密码。要恢复时点「打开文件 / 导入项目」，选择同一份文件并输入密码。文件密码丢失后无法找回。

Mac 桌面版加密保存工作区，密钥由 macOS 钥匙串保护。浏览器预览把编辑内容保存在当前页面内存，刷新或关闭页面前请先导出。导入的视频原文件和主动复制到系统剪贴板的文字由各自的保存位置管理。

## 从源码运行

在装有 Node.js 22.12 或更高版本及 npm 的 Mac 上，在源码目录运行以下命令启动桌面版。

```sh
npm ci
npm run build
npm start
```

运行 `npm run dev` 可预览浏览器界面。运行 `npm run check` 可执行项目测试。
